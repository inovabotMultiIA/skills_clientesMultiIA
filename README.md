# Skills para Clientes MultiIA

Repositório de habilidades genéricas e compartilháveis para clientes e colaboradores que usam MultiIA Agentes.

## Segurança de publicação

Antes de publicar uma skill neste repositório, remova:

- nomes ou dados de clientes;
- credenciais, tokens e segredos;
- URLs privadas ou ambientes internos;
- identificadores internos de reuniões, cards ou sistemas;
- regras comerciais proprietárias.

## Estrutura

- `skills/product-management/`: habilidades reutilizáveis para onboarding, suporte, vendas e acompanhamento operacional.
